## Recording Recovery Rules

If the live page stalls, return to the deck immediately and use Slide 19. If browser voice fails, use the scenario buttons; do not troubleshoot microphone permissions in the recording. If an image is still loading, continue with the evidence table rather than refreshing repeatedly. If a scenario does not match the expected result, stop the recording, preserve the failure, diagnose it, and rerun only after the artifact and iteration log are updated.
