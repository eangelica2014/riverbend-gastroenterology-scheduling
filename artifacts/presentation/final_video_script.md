## Recovery Script

If the live prototype is unavailable, remain in the deck and use Appendix Slide 16. Say: “The live artifact is also independently accessible; I’ll use the embedded evidence route so the recording remains focused.” If voice input fails, use the scripted scenario and say: “Voice is progressive enhancement; the policy and tool proof does not depend on microphone access.” If a scenario produces an unexpected result, stop the recording, preserve the failure, diagnose it, update the iteration log, rerun validation, and record again.
